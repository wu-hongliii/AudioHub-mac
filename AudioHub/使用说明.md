# AudioHub for Mac · 预览版

目标：macOS 12 及以上，Intel x86_64 / Apple Silicon arm64。
当前为待真机验收的预览版，不代表所有 macOS 版本均已验证。

## 安装

1. 退出原版 Background Music（如已安装）。本版沿用其音频驱动、标识和安装位置，会替换原版，不可并行运行。
2. 打开配套 PKG，按提示安装应用、虚拟音频设备和辅助服务。安装驱动需要管理员授权，安装期间声音可能短暂中断。
3. 启动“应用程序”里的 Background Music.app（AudioHub 修改版，保留上游内部名称）。首次请求麦克风权限是为了访问虚拟音频设备，请按系统提示授权。
4. 顶部菜单栏图标提供应用音量、输出设备选择；AudioHub 默认关闭自动暂停，静音不会暂停播放器。
5. 点击菜单第一项“AudioHub 网页音源…”，打开网页控制窗口。

## 导入 Edge 扩展

1. 在网页音源窗口点击“打开扩展文件夹”。
2. 在 Edge 地址栏输入 edge://extensions，打开开发人员模式，点击“加载解压缩的扩展”。
3. 选择刚打开的 edge 文件夹（包含 manifest.json）。
4. 刷新原先已打开的音视频网页，再播放。网页会自动出现在 AudioHub 窗口。
5. 左侧图标静音/恢复，滑块调节普通音视频元素音量。浏览器和设备总音量仍会影响网页。

本版仅配置 Edge。Chrome、Firefox、Safari 尚未完成适配。纯 Web Audio 或受限网页可能只能静音。
网页标题、域名和状态只通过当前用户本机 Unix socket 通信；不录音、不上传网页数据。

## 真机验收（发布稳定版之前必须完成）

- Intel macOS 13.7.4：安装、授权、软件音源静音/恢复、网页自动发现、独立调音量。
- macOS 12：启动与实际声音输出，不能只检查最低部署版本标记。
- Apple Silicon：原生启动、内置扬声器/有线/蓝牙耳机切换。
- 所有机型：连续快速切换、网页导航/关闭、休眠恢复、退出恢复原设备、卸载后恢复声音。
- 确认屏幕录制/会议、DRM 等特殊音源的限制并记录，不能笼统宣称全部兼容。

## 卸载与恢复

先退出应用，按仓库 MANUAL-UNINSTALL.md / uninstall.sh 清理 Background Music 驱动和辅助服务。不要只删除应用留下驱动。
Edge 中移除 AudioHub 网页音源扩展；删除当前用户 Library/Application Support/Microsoft Edge/NativeMessagingHosts/com.audiohub.edge.json（仅当其中 path 仍指向本应用时）。
如果没有声音，在 macOS 声音设置中改回实际扬声器或耳机；保留安装日志以便排查。
